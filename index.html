Knights Honest Housing

A review site where UCF students rate apartments honestly. Reviewers verify with a UCF email address, but their reviews stay anonymous: identities live in a separate table that review records never point to. Students can rate, upload photos, and filter listings by price, location, and rating.

React, Vite, Node.js, Express, Supabase, Resend, Vercel

Visit knightshonesthousing.com

Autonomous Research Agent

An agent that answers a research question by planning sub-questions, searching the web, and writing a report with sources. A verification layer then checks each claim in the report against the source text and measures how much of the report is actually supported.

Python, Llama 3.3 70B on Groq, Tavily search, trafilatura

View code on GitHub

68.7% of claims grounded in sources across a five-question benchmark, with zero fabricated claims.

Neural network from scratch

A small neural-network library written in pure Python, with every gradient computed by hand-derived chain-rule code, used to train a classifier that detects counterfeit banknotes. PyTorch appears only in the tests, as a check on my gradients.

Python, UCI Banknote Authentication dataset

View code on GitHub

98.5% test accuracy, and it caught every forged note in a 274-note test set. Gradients match PyTorch to within 1e-9.

Hospital admission prediction dashboard

A model and dashboard that predict whether a patient will be admitted and explain each prediction with SHAP values. Synthetic patient records flow through a bronze, silver, and gold medallion pipeline before they reach the model.

Python, SHAP, Supabase, Palantir Foundry

AUROC of 0.81, with a per-patient explanation behind every prediction.
